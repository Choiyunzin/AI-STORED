# 검증 결과

검증일: 2026-10-15 · 환경: Linux, Node 22, Chromium(헤드리스, Playwright) · 명령: `npm test`, `npm run build`, `npm run e2e`

## 1. 실행한 검증

### 빌드
- `npm run build` (오디오 매니페스트 생성 → `tsc --noEmit` strict 타입 검사 → Vite 빌드): **통과**. 결과물 JS 약 150KB(gzip 48KB), CSS 약 25KB, 외부 의존 자산 없음.

### 로직 단위 테스트 (`tests/game.test.ts`, 11개 모두 통과)
DOM 없이 `src/logic/game.ts` 상태 전이를 직접 돌립니다.

- **전체 경로 4,000+개**: 사건별 모든 조합(사건 ① 18가지, 사건 ② 108가지, 사건 ③·후속·보고 432가지) + 무작위 전체 경로 4,000개를 처음부터 최종 보고까지 진행. 모든 경로에서
  - 진행 불능 없음 (사건 ③ 완료, 후속 사건 모두 처리 가능, 보고 도달)
  - AI 이용권·작업 여유가 음수가 되지 않음
  - **로그의 비용 합 = 실제 자원 변화** (UI·회고·내려받기가 같은 상태를 봄)
  - 후속 사건 1~2개, 회고 ‘잘 연결한 행동’ 정확히 2개, ‘바꿔볼 행동’ 0~2개
  - 화면만 있는 HTML이 ‘자동 취합 완료’ 상태로 남는 경로 없음, 지원 요청은 ‘요청 중’으로 남음
  - 과장 보고는 항상 정정 비용 발생 (유리해지는 경로 없음)
  - 반환되는 모든 대사 ID가 `dialogue.json`에 존재
  - **후속 사건 12종과 회고 규칙 32종이 각각 최소 한 경로에서 실제로 발생** (죽은 분기 없음)
- 개별 규칙: 중복 결정 시 비용 1회만 차감 / 작은 수정은 직접, 대량 분석은 AI 초안+확인이 효율적 / 최신 공지 없이 검증 AI만 쓰면 작년 절차가 남고 희연 확인이 잡아냄 / 병렬 작성은 변경이 있을 때만 재작업 / A·B·C 세 방식 모두 보완하면 문제 없이 끝남 / 이용권 바닥 시 사람이 대체 처리 / 작업 여유 바닥 시 초과 기록 / 보안 사고 3단계 수습 / 키 결정은 정리 수준 3에서만 / 회고가 선택하지 않은 일을 말하지 않음

## 2. 실행하지 못했거나 추정인 항목

- **완주 시간은 측정하지 않았습니다(추정).** 한 경로에서 재생되는 대사는 약 40~45줄(평균 39자), 한국어 TTS 기준 줄당 5~6초 → 음성 약 4~4.5분 + 읽기·조작 4~5분으로 **약 8~10분으로 추정**합니다. 자동 테스트는 대사를 건너뛰므로 시간 근거가 되지 않습니다. 실제 팀원 대상 플레이테스트로 확인이 필요합니다.
- **실제 브라우저 TTS 음질·억양**은 확인하지 못했습니다(헤드리스 환경에는 한국어 음성이 없어 가짜 TTS로 동작 경로만 검증). Windows(예: Microsoft Heami/InJoon), macOS(Yuna 등)에서 실제 소리를 들어보고 설정 화면에서 배정을 조정하세요.
- **실제 음성 파일 재생**은 제작된 mp3가 없어 성공 경로를 검증하지 못했습니다(누락 시 TTS 대체만 검증). 파일 추가 후 한 번 들어보세요.
- BGM·효과음은 헤드리스에서 오류 없이 생성되는 것만 확인했고, 실제 소리 크기·균형은 듣고 확인하지 않았습니다.
- Edge 온라인 Natural 음성과 새 BGM은 이 환경에서 실제 소리를 들어 확인하지 못했습니다.
- 드래그 앤 드롭은 자동 테스트하지 않았습니다(같은 작업을 하는 버튼 경로로 검증).
- Safari·Firefox, 스크린리더는 테스트하지 않았습니다.
