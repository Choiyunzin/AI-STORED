# 음성 구현 상태와 교체 방법

## 현재 실제 상태 (정직한 요약)

| 항목 | 상태 |
| --- | --- |
| 사전 제작 음성 파일 | **0개 / 122줄 — 전부 미제작** (`scripts/dialogue.csv`의 `audioStatus` 열) |
| 브라우저 TTS | 동작함. 이 PC에 설치된 **한국어 로컬 음성**(`localService=true`)으로 읽음 |
| 캐릭터별 음색·억양 | **보장하지 않음.** TTS는 높낮이·속도만 바꿀 수 있어 성별 음색, 광주·경상도 억양을 정확히 재현하지 못함 |
| 7명 서로 다른 목소리 | **보장하지 않음.** 한국어 음성이 1~2개뿐인 PC가 많아 여러 캐릭터가 같은 음성을 높낮이만 달리해 공유함 |
| 음성 없는 환경 | 자막으로 끝까지 진행 가능 (검증 완료) |

게임 안 **⚙ 설정 → 캐릭터별 음성 배정**에서 각 캐릭터에 실제로 적용된 음성 이름, 높낮이/속도, 자동 배정 근거(“여성 추정 음성”, “성별 정보 없는 음성 · 높낮이로만 구분” 등)를 볼 수 있고, 캐릭터마다 음성을 직접 고르거나 “자막만”으로 지정할 수 있습니다.

## 사람처럼 들리게 하려면

1. **가장 쉬운 방법 — Microsoft Edge에서 ‘🎙 자연스러운 음성으로 시작’**: Edge의 한국어 Natural 음성(SunHi, InJoon, HyunSu 등)은 신경망 음성이라 사람 말투에 가깝고 캐릭터별로 다른 음성을 배정할 수 있습니다. 단, 온라인 음성이라 대사 텍스트가 Microsoft 음성 서비스로 전송됩니다. Chrome은 ‘Google 한국의’ 음성 1개뿐입니다.
2. **실제 사람/고품질 음성 파일**: 성우 녹음이나 신경망 TTS 서비스(예: Typecast, Naver Clova Voice, ElevenLabs)로 만든 mp3를 아래 방법으로 넣으면 사투리 억양까지 캐릭터별로 확정할 수 있습니다. 파일은 게임 실행 중 외부 호출 없이 재생됩니다. (이 개발 환경에서는 음성 생성 서비스 접속이 네트워크 정책으로 막혀 파일을 만들지 못했습니다.)

## 재생 우선순위

1. `public/audio/<speakerId>/<대사ID>.mp3` 가 `public/audio/manifest.json` 에 있으면 그 파일을 재생
2. 없거나 재생 실패(404·디코딩 오류·4초 무응답)면 브라우저 한국어 TTS
3. 기본값은 **이 PC에서 처리되는 로컬 음성만** 사용. 원격(온라인) 음성은 설정에서 사용자가 직접 켜야 하며, 켜면 대사 텍스트가 외부 음성 서비스로 전송될 수 있다는 경고가 표시됨
4. 한국어 음성이 없거나 TTS가 차단·지연되면 “이 PC에서 사용할 수 있는 한국어 음성을 찾지 못했습니다” + **재시도 / 음성 설정** 버튼을 보여주고 자막으로 계속 진행

한 번에 한 사람만 말합니다. 다음 대사·건너뛰기·장면 전환·음소거 시 이전 재생과 대기열을 취소합니다. 말하는 동안 대화창 초상화와 왼쪽 팀원 목록에 입 모양 애니메이션이 켜지고 배경음악이 줄어듭니다.

## 음성 파일 추가·교체 방법

1. `scripts/dialogue.csv` 를 엑셀 등으로 열어 대본으로 사용합니다(UTF-8 BOM, 122줄 — 탐색 화면에서 다가가면 나오는 `amb_*` 대사 23줄 포함). `voiceDirection`은 `scripts/voice-mapping.csv` 참고.
2. 녹음·생성한 파일을 **대사 ID 그대로** 저장합니다.
   ```
   public/audio/hong/intro_hong_01.mp3
   public/audio/chian/ev1_chian_01.mp3
   ```
   - 폴더 이름은 `speakerId` (`hong, sujin, jongyun, chian, heeyeon, heoin, yunjin`)
   - 대사 ID는 분기 대사까지 모두 고정되어 있으므로 문장을 고쳐도 ID는 유지하세요.
3. 매니페스트와 대본 상태를 갱신합니다.
   ```bash
   npm run audio:manifest   # public/audio/manifest.json 갱신 (npm run build 에도 포함)
   npm run dialogue:csv     # dialogue.csv 의 audioStatus 를 제작됨/미제작으로 갱신
   ```
   1KB 미만 파일은 빈 파일로 보고 무시합니다(빈 파일로 ‘제작됨’을 가장하지 않도록).
4. 일부 대사만 파일이 있어도 됩니다. 파일이 없는 대사는 TTS 또는 자막으로 재생됩니다.

## 실제 팀원 목소리에 대하여

이 프로젝트의 음성 연출 방향은 **캐릭터에 어울리는 연기 방향**이며 실제 인물의 목소리를 복제하라는 요구가 아닙니다. 실제 팀원의 목소리를 녹음해 쓰려면 본인 동의를 받으세요.
